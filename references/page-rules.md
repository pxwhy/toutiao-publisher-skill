# 头条号页面规则

默认登录页：

```text
https://mp.toutiao.com/
```

默认发布页：

```text
https://mp.toutiao.com/profile_v4/graphic/publish
```

填充规则：

- 页面定位优先读取 `config/selectors.json`。
- 标题最多填充 80 字。
- 正文优先定位 `contenteditable` 或 `ProseMirror` 编辑器。
- 图片可以为空；有图片时先下载或复制到 run 目录，再上传到页面。

发布选项：

- 优先选择“投放广告赚收益”。
- 默认不选择“头条首发”；只有输入 JSON 的 `options.first_publish` 为 `true` 时才点击。
- 若存在“个人观点，仅供参考”，按页面要求勾选。
- 若出现“作品同步授权”弹窗，点击“确定”属于平台正常授权确认。

按钮链路：

- 兼容 `发布`。
- 兼容 `预览并发布`。
- 兼容 `确认发布`。
- 兼容授权弹窗中的 `确定`。

失败和风控：

- 看到 `验证码`、`滑块`、`安全验证`、`环境异常`、`操作频繁`、`登录已失效` 必须失败退出。
- 看到 `发布失败`、`保存失败`、`请填写`、`请上传`、`审核不通过`、`操作失败` 必须失败退出。
- 不允许实现绕验证码、绕风控逻辑。
